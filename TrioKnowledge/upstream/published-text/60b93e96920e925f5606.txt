Sometimes, people have their macOS privacy settings configured so that Xcode does not have permission to access their computer's 'Downloads' folder. This can become problematic when using the build script to build an app with Xcode. To ensure access is allowed, follow these instructions:   Select the 'Apple symbol' in the top left-hand corner of the screen.   Next, select 'System Settings'.    Next, we are going to select 'Privacy & Security".   Then, we are going to select the 'Files & Folders' option.    We can then select the Xcode application.    Once you select the Xcode application, ensure access to the downloads folder is toggled on.

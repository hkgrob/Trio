If you are someone who already has a lot of forks in your personal account and want to switch to using a GitHub organization. Here's how:  Follow the steps to create your organization Create a Free GitHub Organization   Add the Secrets and the Variable to your GitHub organization as explained in Prepare to Enter Secrets Fork all the repos you normally use, but this time, set your organization as the owner For each repository in your organization: Tap on the Actions tab Enable Actions Run the Create Certificates Action and wait for success Run the Build Action WHAT?? That's right - all the setup is done on the Apple side and you already did that If you successfully built with your private GitHub account, everything is already configured The one thing you might want to do is copy customizations from your personal account fork to the organization fork     Return to your private GitHub account Your choice: either delete the forks in your personal account or at least disable the building from your personal account    Important Your personal GitHub account is still needed. The free organization points to your personal account as a member. If you delete your personal GitHub account, you lose access to your organization account too.

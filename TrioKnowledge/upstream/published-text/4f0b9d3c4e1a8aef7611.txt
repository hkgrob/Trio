*Feature Branch Accu-Chek SmartGuide is currently only available in the dev branch. See here for help on building the dev branch with Browser Build. Trio suports the Accu-Chek SmartGuide CGM. This is a 14-day CGM from Roche. It requires 2 calibrations: one after 12h and one 0.5-2.5h after the first calibrations. These calibrations are required, but can be done within Trio. You can use this CGM with one Trio (including calibrating the CGM) or use it along side the official SmartGuide app and SmartGuide Predict app.

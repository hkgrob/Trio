API Key  vs APN Key If you use Remote Commands with Nightscout or Trio, you may notice the Application Programming Interface (API) key has the same type of format as the Apple Push Notification (APN) key. The keys for both of these purposes are p8 keys, but they should not be confused with each other. The Secrets for building with GitHub use the API Key. The config vars for Nightscout, Trio and Loop use the APN Key.

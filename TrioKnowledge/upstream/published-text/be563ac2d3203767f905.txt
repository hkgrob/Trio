These steps are for people who build Trio with Xcode on a Mac. The easiest way is to download a fresh copy of the released code rather than changing the copy you already have.  Follow Build Trio with Xcode from the beginning When the Build Select Script asks you which branch to build, type 1 and press return to select main Continue with the normal build steps  Your settings and pod session are preserved as long as you sign with the same Apple Developer Account as before.

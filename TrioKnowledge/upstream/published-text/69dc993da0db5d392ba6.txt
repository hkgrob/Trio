If you previously followed Configure the dev branch as default, you need to reverse it. If you never changed your default branch, skip to Update Your Fork. Only the owner of the repository can do this, and you must be logged in — otherwise the Settings tab does not appear.   Click on the Settings icon near the top right of your Trio repository  You may need to scroll down to see the Default Branch Do not tap on the Branches tab on the left under Code and Automation, that is not the correct menu     To the right of the default branch name there is a pencil and a left-right arrow icon (⇄)  Tap on the left-right arrow icon (⇄) to bring up the Switch default branch to another branch dialog    Click on the dropdown next to the current default branch, in this case dev    Select main  Click on the Update button You will be presented with an are-you-sure question Click on the red I understand, update the default branch. button    Your default branch is now main, and your weekly automatic builds will follow main from here on.

Pro Tip: Use the same folder as your Secrets Reference File It's a good idea to keep all your important files in one place. You probably set up a folder for your Secrets Reference File. Use the same folder for your API key - be sure to label the file so you know what the key is. For example, change the name from KPMAM8y3G5.p8 to API_KEY_KPMAM8y3G5.p8.

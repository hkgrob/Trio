The first time you open Xcode, it will want to install a package of command-line tools. Please wait patiently for this to be completed. In some instances, the command-line tools may have been installed without asking. Before proceeding, please confirm that the tools have been installed correctly.   Open Xcode.   In the top left-hand corner of the screen, select 'Xcode'.   Next, select 'Settings'. This will open the Xcode 'Settings' window.   In the Xcode 'Settings' window, select 'Locations'   In the 'Locations' tab, you will observe a drop-down menu for 'Command Line Tools'. Ensure the Xcode version listed matches the version you just downloaded and installed.

Benefits of Loop  A very clean, minimalistic user interface A built-in onboarding guide Simple settings A dedicated Loop Follow app for caregivers  Benefits of Trio  Unannounced meals Less user interaction/correction Dynamic ISF and CR Highly customizable temporary profiles Adaptive algorithm  Should I switch from Loop to Trio?  If Loop works well for you, you should not switch to Trio. Switching to Trio will not resolve Loop build issues. The build process is the same for both Loop and Trio. If you find it difficult to understand how Loop works, Trio is even more complex.  You should consider switching to Trio if you've been using Loop for a while and have issues that Loop can't solve even after tweaking and re-tweaking your settings and profile.

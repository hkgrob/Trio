Default: OFF When this setting is enabled, Super Micro Boluses (SMBs) will always be allowed if dosing calculations determine insulin is needed via the SMB delivery method. The exception is when a high temp target is set. Enabling SMB Always will remove the other redundant "Enable SMBs if..." options.   SMBs will remain on if you have a low temporary target set but will be fully disabled if a high temporary target is set (unless "Allow SMB With High Temptarget" is enabled).   The size of SMBs is limited by Max SMB Basal Minutes.

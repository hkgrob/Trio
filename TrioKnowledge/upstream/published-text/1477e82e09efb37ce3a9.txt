SMB (Super Micro Bolus) is an oref algorithm feature that delivers small, frequent boluses instead of temporary basal adjustments, creating a more responsive system. Tip  Best practice is to have both UAM and SMBs enabled at the same time. If you enable any SMBs, also enable UAM. Individual SMB Options are inclusive, not exclusive. Only ONE enabled setting needs to be true for SMBs to be allowed. More info in the flow chart: Are SMBs Allowed?

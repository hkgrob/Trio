If you are not comfortable using the  command line in a terminal on Windows, consider using a graphical application instead; otherwise, keep reading. Choose your favorite Windows Shell below PowerShell or "Command Prompt (CMD)", then follow the instructions. PowerShellCommand Prompt (CMD)  Open PowerShell:   Right-click the Start menu Select Windows PowerShell.   Navigate to Log Folder: cd $HOME\Downloads
     Replace $HOME/Downloads with the folder where you downloaded the log files. Run Compression Command: Compress-Archive -Path log.txt, log_prev.txt -DestinationPath triologs.zip
     where: -Path is followed by the files to compress. -DestinationPath is followed by the name of the ZIP archive file.   Verify Archive:     A new triologs.zip archive file appears in the same folder.   Open Command Prompt:   Click the Start menu Type cmd. Press Enter.   Navigate to Log Folder: cd %USERPROFILE%\Downloads
            Replace %USERPROFILE%\Downloads with the folder where you downloaded the log files. Run Compression Command:  tar -a -c -f triologs.zip log.txt log_prev.txt
      where: tar is the archiving utility. -a selects the archive format based on the file extension (.zip in this case). -c creates a new archive. -f is followed by the name of the archive file. log.txt log_prev.txt are the files to include in the archive.   Verify the Archive:     A new triologs.zip archive file appears in the same folder.

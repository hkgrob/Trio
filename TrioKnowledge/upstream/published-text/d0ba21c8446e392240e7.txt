xDrip4iOS To use xDrip4iOS as a CGM source, you must build it yourself with the same Apple Developer account you used to build your Trio app. Please see the following for instructions on how to build xDrip4iOS yourself here.   Tip If you use xDrip4iOS with the Dexcom G6/ONE, in Trio select Dexcom G6 as the CGM source. Trio will intercept glucose readings directly from the transmitter. Nightscout Yes. Nightscout can be used as a remote CGM source in Trio. However, this option should be avoided because it does not keep Trio running in the background like other CGM options. You will have to open Trio manually to make it run loop cycles.

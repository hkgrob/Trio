Here are some things to keep in mind after upgrading from Trio 0.2 to Trio 0.5 (or higher) in the first 3 hours:  Dynamic ISF & Autosens     Dynamic ISF is disabled for the first 7 days. You may need to enter carbs and bolus during this time if you aren't already doing so. Autosens will be used instead (but there's a long standing issue with autosens where it will likely be stuck at 1 when there are carb entries or SMBs.) Onboarding Wizard     Take this time to go through the Onboarding Wizard. Reference the New User Setup Guide or ask questions on Facebook or Discord if you have any questions. Test Settings     This is a great time to test your settings so you can start fresh on solid footing. New User Interface     Use this time to learn the New User Interface.  Do not use a pump or cgm simulator  Doing so will result in false data being stored and you will have to delete the app with all the data and reinstall before you can use it on a live pump. This will also reset your 7-day waiting period for Dynamic ISF. More information on simulator use

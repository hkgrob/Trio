The dev branch of the nightscout/Trio repository will be updated frequently. This is how you know if your fork needs to be updated as well. As long as the automatic runs are happening weekly for your repository — you will not need these manual instructions, unless you want to manually build an update sooner. Tap the Code button (upper left) and ensure this branch in your fork is up to date.  Select the desired branch in the dropdown menu (this graphic shows main branch, to get 0.5 (or newer), you must choose dev branch) If the message indicates this branch is "behind", tap on the sync fork button and then the Update branch button

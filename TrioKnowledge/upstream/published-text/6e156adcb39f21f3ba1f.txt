If you have not already made up a password, do it now and record it as MATCH_PASSWORD. Note that if you build more than one app, you use the same MATCH_PASSWORD for all the apps. Every app needs to have the same 6 Secrets. What is this Password used for? The MATCH_PASSWORD is a special password called a passphrase that is used to encrypt and decrypt your certificates from Apple so they can be used when building with GitHub; it helps keeps your certificates secret and safe. A passphrase is a little different from a regular password. A password is what you usually use to log in to a website or game. A passphrase is a secret code that helps protect important files by adding an extra layer of security when files are encrypted.
